# 🗳️ Ballot Box – Blockchain Based Voting System

Ballot Box is a decentralized electronic voting system built using **Blockchain technology** to ensure secure, transparent, and tamper-proof elections.  
The system leverages **Ethereum smart contracts** to record votes immutably and prevent manipulation.

---

## 🚀 Features
- Secure and transparent voting using Blockchain
- Ethereum smart contracts for vote storage
- One person – one vote mechanism
- Real-time vote counting
- Tamper-proof and verifiable election results
- User-friendly web interface

---

## 🛠️ Tech Stack
- **Backend:** Node.js  
- **Blockchain:** Ethereum  
- **Smart Contracts:** Solidity  
- **Frontend:** HTML, CSS, JavaScript  
- **Blockchain Tools:** Web3.js,  Ganache (optional)
